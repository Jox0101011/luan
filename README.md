## luan
*test for minimalist parsers in ruby by lay*

## explain what is this
*Parser for text to macros*
**This project is not totally serious, I did it to demonstrate some things and test parsers, in addition, I really wanted to show a friend from school about a tool with his name, so if you see this project do not judge its simplicity, it was purposely made to be simple**

## install and uninstall
*with sudo*

```sh
sudo ./setup.sh --unistall    # or --uninstall to uninstall
```

```sh
sudo ./setup.sh               # to install
```

*with doas*

```sh
doas ./setup.sh --uninstall   # or --unistall to uninstall
```

```sh
doas ./setup.sh               # to install
```
